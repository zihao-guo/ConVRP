# Processed ABD Data
Generated by:
```bash
python3 data/processed/scripts/reproduce_abd_data.py --overwrite
```
The canonical processed data are the 138 JSON files under `omega100` and `omega500`.
`data/processed/scripts/process_alvarez_abd.py` is an auxiliary processor produced during the subagent pass; the final ABD reproduction uses `reproduce_abd_data.py` because it incorporates the extended-C raw source needed for set D.
## Paper Rules Implemented
- Base deterministic instances: 10 from A, 7 from B, 6 from D.
- Scenario counts: `|Omega| in {100, 500}`.
- Customer occurrence probabilities: `alpha in {0.2, 0.5, 0.8}` for every customer.
- Demand uncertainty: discrete uniform integer demand in `[ceil(dbar_i * (1 - epsilon)), floor(dbar_i * (1 + epsilon))]` with `epsilon = 0.5`, lower bounded by 1.
- Nominal demand: `dbar_i = 2` for set A; maximum positive observed deterministic demand for sets B and D.
- Scenario probability: `1 / |Omega|`.
- Vehicles: `max(ceil(2 * dmax_Omega / Q) - 1, D + 1)` with `D = 1`.
- Penalties: `b_i = 3 * (2 c_0i)` and `o_i = 0.1 * (2 c_0i)`.
